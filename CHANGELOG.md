# Changelog

## 0.1.0 (Minecraft 1.21.1, NeoForge)
First release of the 1.21.1 port.

* Ore Scanner module: values the ore in a box behind the clicked face using `c:ores` tags and a configurable value list; per-axis radius tweaks; FE cost per block scanned.
* ME Wireless Terminal module: opens an Applied Energistics 2 or ae2wtlib wireless terminal from the inventory and charges it from the suit. Optional AE2 support.
* Server config, synced to clients.
* Module tooltips show the description and stats like built-in Modular Powersuits modules; both modules also appear in the Modular Powersuits creative tab.
